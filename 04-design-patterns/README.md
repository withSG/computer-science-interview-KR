# 디자인 패턴 (Design Patterns)

> 소프트웨어 설계의 재사용 가능한 해결책

## 학습 목표

- [ ] 생성 패턴을 이해하고 적용할 수 있다
- [ ] 구조 패턴의 목적을 안다
- [ ] 행위 패턴을 설명할 수 있다
- [ ] 데코레이터와 프록시처럼 구조가 닮은 패턴을 의도로 구분할 수 있다
- [ ] MVC / MVP / MVVM의 데이터 흐름 차이를 설명할 수 있다
- [ ] 레이어드와 헥사고날 아키텍처의 의존 방향을 비교할 수 있다
