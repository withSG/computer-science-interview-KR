# 네트워크 (Network)

> 웹 개발자가 알아야 할 네트워크 기초 지식

## 학습 목표

- [ ] OSI 7계층과 TCP/IP 4계층을 설명하고 캡슐화 과정을 그릴 수 있다
- [ ] TCP가 신뢰성을 만들어내는 방식과 UDP를 고를 기준을 안다
- [ ] HTTP의 무상태성·메서드·상태 코드와 버전별 진화를 설명할 수 있다
- [ ] 도메인이 IP로 해석되는 과정과 캐시 계층을 순서대로 말할 수 있다
- [ ] TLS 핸드셰이크와 인증서 검증이 무엇을 보장하는지 설명할 수 있다
