# 인성 면접 (Personality Interview)

> 기술 질문이 아니라 경험·태도·가치관을 묻는 면접입니다. 자주 나오는 질문을 모아 두고, 답을 스스로 준비해 보는 용도로 씁니다.

## 학습 목표

- [ ] 자주 나오는 인성 면접 질문에 1분 안팎으로 답할 수 있다
- [ ] 성공·실패·협업·갈등 경험을 STAR 기법으로 정리할 수 있다
- [ ] 강점과 단점을 구체적인 경험 근거와 함께 말할 수 있다
- [ ] 지원 동기와 가치관 질문에 회사와 직무를 연결해 답할 수 있다
