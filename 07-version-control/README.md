# 버전 관리 (Version Control)

> Git의 핵심 개념과 협업 전략

## 학습 목표

- [ ] Git이 스냅샷을 저장한다는 말의 의미와 객체 4종의 관계를 설명할 수 있다
- [ ] 작업 디렉토리 / 스테이징 / 저장소 세 영역과 명령어의 이동 경로를 구분할 수 있다
- [ ] merge와 rebase가 커밋 그래프를 어떻게 다르게 만드는지 그릴 수 있다
- [ ] 충돌이 발생하는 조건과 해결 절차를 안다
- [ ] reset / revert / restore를 상황에 따라 근거를 대며 선택할 수 있다
- [ ] 브랜칭 전략을 팀 상황에 맞게 고르고 그 이유를 설명할 수 있다
