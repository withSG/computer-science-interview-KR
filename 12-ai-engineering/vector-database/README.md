# 벡터 데이터베이스 (Vector Database)

> 고차원 벡터의 효율적인 저장과 검색

## 학습 목표

- [ ] 벡터 데이터베이스의 필요성을 이해한다
- [ ] ANN 알고리즘 (HNSW, IVF)을 설명할 수 있다
- [ ] 주요 벡터 DB를 비교할 수 있다
- [ ] 유사도 측정 방식의 차이와 정규화의 역할을 설명할 수 있다
- [ ] 메타데이터 필터링의 트레이드오프를 안다
