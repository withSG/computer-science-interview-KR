# 클라우드 기초 (Cloud Fundamentals)

> 클라우드 컴퓨팅과 가상화의 핵심 개념

## 학습 목표

- [ ] 클라우드 서비스 모델(IaaS, PaaS, SaaS)을 책임 경계로 구분한다
- [ ] 가상화와 하이퍼바이저의 원리를 안다
- [ ] 클라우드 배포 유형을 규제·락인·비용 관점에서 비교할 수 있다
- [ ] 확장성과 고가용성 개념을 설명하고 가용성 수치를 다운타임으로 환산할 수 있다
- [ ] SPOF를 찾아내고 RTO/RPO에 맞는 DR 전략을 고를 수 있다
