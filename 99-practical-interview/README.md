# 실전 면접 (Practical Interview)

> 기술 면접 준비와 인성 면접 대응

## 학습 목표

- [ ] 기술 면접이 평가하는 네 가지 축을 구분할 수 있다
- [ ] 모르는 질문에 추론까지 보여주는 답변을 만들 수 있다
- [ ] 결론 먼저 구조로 답변을 구조화할 수 있다
- [ ] STAR 기법으로 경험을 정리할 수 있다
- [ ] 자기소개와 지원동기를 회사 조사와 연결해 준비한다
- [ ] 기술 선택 이유를 대안·기준·트레이드오프로 설명할 수 있다
- [ ] 성능 개선 경험을 측정 기반으로 서술할 수 있다
